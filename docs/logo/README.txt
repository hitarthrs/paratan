ParaTAN logo files
==================
All files are pure vector SVG. The wordmark text is converted to outlines
(Source Serif 4: "Para" Regular, "TAN" Bold), so no font install is needed.

Colors (only two):
  Red    #C5050C
  White  #FFFFFF

Files
  paratan-icon.svg                      Icon: red tile, white shapes
  paratan-icon-reversed.svg             Icon: white tile, red shapes (place on red)
  paratan-lockup.svg                    Icon + ParaTAN, red on transparent
  paratan-lockup-reversed.svg           Icon + ParaTAN, white on a red background
  paratan-lockup-tagline.svg            Lockup with tagline
  paratan-lockup-tagline-reversed.svg   Reversed lockup with tagline
